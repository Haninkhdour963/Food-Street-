# Food-Street-
🍔 Street Food – Responsive Restaurant Landing Page
A modern, fully responsive restaurant landing page built with HTML5, CSS3, and JavaScript.
It showcases a restaurant's menu, offers, booking form, testimonials, and contact details with a visually appealing design and smooth navigation.

🚀 Features
Responsive Design – Works seamlessly on desktop, tablet, and mobile devices.

Navigation Bar – Includes quick links for Home, Menu, About, and Booking.

Hero Slider – Displays a rotating image gallery with a call-to-action button.

Special Offers Section – Highlights featured dishes with prices and "Add to Cart" buttons.

Menu Section – Categorized menu items (Burger, Pizza, Pasta, Fries, All).

About Section – Restaurant introduction with an image and description.

Table Booking Form – Allows users to reserve a table by filling out a form.

Google Maps Integration – Shows restaurant location with an optional ad space.

Customer Testimonials – Slider showcasing customer reviews.

Footer – Includes contact details, quick links, opening hours, and social media icons.

🛠️ Technologies Used
HTML5 – Semantic structure and content.

CSS3 – Styling using multiple section-specific stylesheets.

JavaScript (Vanilla) – Interactive elements (slider, menu interactions).

Normalize.css – CSS reset for consistent styling across browsers.

Google Fonts (Roboto) – Elegant typography.

Favicon & Icons – Custom icons for branding.
🎯 Customization
Change Menu Items: Update index.html under the Our Menu section.

Update Images: Replace files in assest/images/.

Modify Colors & Fonts: Edit assest/css/style.css.

Edit Location: Update the Google Maps iframe in the Book a Table section.
